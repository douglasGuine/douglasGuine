Desenvolvedor Full Stack na **Single Future**, atuando na construção de uma plataforma web com **Angular 18, Spring Boot 3, Java 17 e PostgreSQL**. Trabalho o ciclo completo: modelagem de dados, regras de negócio, autenticação e autorização, APIs REST em camadas e interfaces responsivas.

## 💼 Experiência

### **Single Future** — *Solutions Engineer | Full Stack Developer*
`fev/2026 — Atual` · São Paulo, Brasil

Desenvolvimento de plataforma web escalável, segura e responsiva, atuando de ponta a ponta:

- **Backend:** APIs RESTful em arquitetura de camadas (Controller → Service → Repository) com Spring Boot 3, Spring Data JPA, Hibernate, validações e tratamento global de exceções
- **Segurança:** autenticação e autorização com JWT + Spring Security, controle de permissões por papéis (`ADMIN`, `PROFESSOR`, `ALUNO`), proteção de rotas e interceptadores HTTP
- **Dados:** modelagem em PostgreSQL com versionamento de migrations via Flyway
- **Frontend:** SPAs em Angular 18 integradas às APIs REST, com Angular Material, Tailwind CSS, dashboards administrativos em Chart.js e animações GSAP
- **Acessibilidade:** conformidade WCAG 2.1 e integração VLibras
- **Ambiente:** Docker Compose para padronização do dev environment, Git/GitHub, Scrum e Kanban

### **C2S | Contact2sale** — *Estagiário em Suporte IA*
`out/2025 — mar/2026` · São Paulo, Brasil

- Análise, diagnóstico e resolução de incidentes em sistemas, com reprodução de cenários e testes funcionais
